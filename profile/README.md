# 🚌 [서비스명 미정]
**용인 대중교통 환승 실패 방지 + 탑승 확률 예측 서비스**
2026 연합 해커톤 용용톤·4팀

## 왜 만들었나요
용인 동백 일대에서 통근·통학하는 사람들은 광역버스를 못 타거나 환승에 실패해서 시간을 자주 잃어요.
단순한 버스 도착 정보와 실시간 잔여 좌석만으로는 "내가 이 버스를 탈 수 있을지"를 알기 어렵습니다.

## 무엇을 하나요
- 출발지와 목적지를 입력하면 현재 경로와 대안 전략(거슬러타기, 우회, 대체 노선)을 비교해 보여줘요.
- 탑승·환승 위험을 가능 / 주의 / 위험 단계로 알려줘요.
- 광역버스의 도착시간을 보정하고, 내가 탈 정류장에 버스가 도착했을 때 남아 있을 좌석 수를 미리 예측해요.
- 이동 중 새 교통정보가 들어오면 경로를 다시 평가하고, 바꾸는 게 실제로 유리할 때만 전략 전환을 제안해요.

## MVP 범위
동백 일대 출발 · 평일 06:00~09:30 · 광역·좌석형 버스 중심
